# Haftalık raporlar

Her üye kendi klasörüne her hafta bir rapor yazar: `raporlar/<ad>/hafta-NN.md`
(ör. `raporlar/nisa/hafta-03.md`). Herkes yalnızca kendi klasörünü değiştirir.

Raporu o haftanın işleriyle birlikte kendi dalında commit'leyin; pull request ile `main`'e girer.
Haftanın lideri videoda "kim ne yaptı" kısmını bu raporlardan hazırlar.

## Şablon

```markdown
# Hafta NN — Ad Soyad

## Yaptıklarım
- X.Y İşin adı: kısa açıklama

## Commit'ler / PR
- PR: <bağlantı>

## Karşılaştığım sorunlar
- ...

## Gelecek hafta
- ...
```
